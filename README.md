# Parser 项目
## 项目简介
简单的字符串处理工具，支持字符串长度统计和文本行数统计功能。
## 核心功能
1.  parse_string：输入字符串，返回其长度（支持空指针安全处理）
2.  count_lines：输入文本（\n 分隔），返回行数
## 操作命令
### 编译
- 默认编译（生成可执行文件）：`make`
- 生成静态库：`make static`
- 生成动态库：`make shared`
### 运行
- 可执行文件：`./main`
### 清理
- 清理所有编译产物：`make clean`
